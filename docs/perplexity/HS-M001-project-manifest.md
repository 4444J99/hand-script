## ChatGPT exports (added v0.3)

Turns 24–26 write the chat's title/front matter and **the content of the notebook PDFs (HS-F001/F002)**. That settles where the PDFs came from: they come out of this chat.

**HS-F011 / HS-T010 · Branch of the above** — Turns 1–22 are identical to HS-T009 (exact match verified). It splits at turn 23, which asks for GitHub best practices and protocols for the organ system instead of going back to scripts. Only turn 23 is in its report.

## Newly inspected files

**HS-F001 / HS-F002 · Unique Scripts Notebook Practice v1 / v2** — tags: handwriting, protocol, Greek-first, lineages. Six-page PDFs generated by ChatGPT (WeasyPrint 65.1): a Notebook Practice Protocol (preparation, six 15–20 min practice steps, script rotation, weekly review), a rationale for starting with the Greek alphabet, and an Index of Referenced Lineages (Ovid, Virgil, Dante, Eliot, Joyce, Warburg, Borges, Calvino, Benjamin, Eco, Flusser) with 30 source notes. **v1 and v2 have identical text**; only the binaries differ, so neither supersedes the other in content. Origin: ChatGPT chat HS-T009, turns 24–26 (identified v0.3); the Perplexity chats only cite them. Report: HS-A003.

**HS-F004 / HS-T002 · Canonical Linguistics — Exhaustive-List Request** — The export holds only a summary of a claimed document: undergraduate (4 semesters), MA (4 semesters), PhD (years 1–4, 14 specialization options), and 16 dissertation subfields from generative syntax to sign-language linguistics. It claims "4,000+ references" and a saved download, but **that document is not in the project**; only the outline survives. HS-T007 is the surviving full-length canon and probably the better replacement. Reference list is mostly tangential journal articles.

**HS-F006 / HS-T004 · Roots and Stems — Comprehensive Guide** — A single-turn long report, the precursor to HS-T005, before handwriting/canonical texts were added. Seven parts: PIE and Latin roots (root table: *gen-, *ped-, *men-, *ghos-ti-, *steh₂-, *ker-…), alphabet systems and how they connect (Greek, Hebrew, Arabic, kanji, Cyrillic), neuroscience-based strategy, integrated timeline, tools, common challenges, advanced integration, first steps. Content that overlaps HS-T005 is kept in both reports; neither duplicates the other.
